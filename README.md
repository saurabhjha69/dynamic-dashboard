# DynamicDashboardApp

A React dashboard project with dynamic widgets, sidebar, and personalized dashboard features.   
Live link: https://dynamic-dashboard-cyan.vercel.app/

---

## Features

- Add / remove / toggle widgets
- Sidebar with tabbed categories
- Search widgets in real-time

---

## Installation

1. Clone the repository:

```bash
git clone https://github.com/saurabhjha69/dynamic-dashboard.git
```
2. Install Dependencies

```bash
npm install
```
3. Start the development server:

```bash
npm start
```
